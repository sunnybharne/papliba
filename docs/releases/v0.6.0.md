# Papliba v0.6.0

Status: Released
Release date: 2026-08-07

## Highlights

- Added multiple draggable Manual Triggers with inline renaming, selection, deletion, and per-trigger Run controls.
- Added selectable, removable, and reconnectable workflow edges, including trigger-to-step connections.
- Added sequential execution feedback with fast energy flowing around active nodes and through connecting wires.
- Restored Python as a draggable workflow step alongside OpenAI and Claude Code tools.
- Added official OpenAI, Claude Code, and Python icons with the shared OpenAI-green visual system.
- Added a focused Python file preview with syntax coloring and double-click access from the canvas.
- Changed Python steps from flat files into named folders containing `main.py`, leaving room for `.env`, requirements, helper modules, and assets.
- Made Python step folders the workspace root for Codex, VS Code, Cursor, Finder, and terminal applications.
- Preserved complete Python step folders during rename, deletion, recovery, and legacy migration.

## Local Python step layout

```text
projects/
  project-name/
    workflow-name/
      python-scripts/
        step-name/
          main.py
          .env
          requirements.txt
          helpers.py
```

Existing flat Python files are migrated automatically and safely when first accessed.

## Notes

Papliba v0.6.0 makes the workflow canvas more expressive and gives every Python step an isolated working directory. Workflow execution is still a frontend demonstration; production execution remains planned for a later release.
