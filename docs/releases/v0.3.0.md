# Papliba v0.3.0

Status: Released
Release date: 2026-08-06

## Highlights

- Refined the first-run organization screen so it avoids repeating the same empty-state message.
- Added a centered organization setup card with guidance to use the sidebar `+` button.
- Added a global search popup from the sidebar search icon.
- Made the sidebar resizable while keeping the collapsed rail fixed.
- Simplified the account menu to only Settings and Log out.
- Tightened sidebar, account menu, header, and empty-state spacing.
- Made sidebar, dropdown, and search animations snappier.
- Improved visual consistency across the sidebar, header, and username footer.

## Notes

This release is focused on making the first Papliba workspace feel calmer, smaller, and easier to explain in a step-by-step video.
