# Papliba v0.4.0

Status: Released
Release date: 2026-08-06

## Highlights

- Unified the popup styling across account, settings, search, and organization dialogs.
- Made organization rows more compact and easier to scan.
- Replaced the organization folder icon with a globe icon.
- Replaced the organization pin/action controls with a direct delete icon.
- Added click-away closing for the organization dropdown.
- Moved organization details into a README-style Markdown panel.
- Added an edit icon for the organization README.
- Refined the Settings window spacing, contrast, and account rows.
- Updated the architecture diagram to show the web UI and local runner split.

## Notes

This release tightens the organization workflow and keeps the UI closer to the simple, compact style Papliba is using for the first product iteration.
