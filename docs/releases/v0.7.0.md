# Papliba v0.7.0

Status: Released
Release date: 2026-08-07

## Highlights

- Added timestamped run logs beside each Python step's `main.py`, with per-step retention configurable from 1 to 100 runs and a default of 10.
- Added Command/Ctrl+C and Command/Ctrl+V duplication for selected nodes, triggers, and their internal connections.
- Added Shift selection, marquee selection, and grouped dragging while preserving node spacing.
- Added draggable input endpoints for moving existing connections between target nodes.
- Fixed marquee selection so its rectangle begins at the pointer rather than the canvas origin.
- Changed workflow execution to follow the actual graph, leave unreachable nodes disconnected, and run sibling branches in parallel.
- Refined the Codex composer with file context, access and model indicators, compact controls, keyboard submission, and a circular send action.
- Made successful Codex Apply actions refresh an already-open Python file preview immediately.

## Python run logs

Completed Python demo steps create files such as:

`run-20260807T133238147Z-20365b3d.log`

Logs are stored in the same step folder as `main.py`. They record completion time, project, workflow, step, input, and output. Retention cleanup is serialized by the local runner so concurrent workflow branches safely keep only the requested number of newest logs.

## Canvas editing

Selected nodes now behave as a group. Copy and paste assigns fresh node IDs, offsets the new group, preserves internal edges, and gives Python copies unique step-folder names. Connected input circles can be dragged to redirect an existing edge in a single undoable action.

## Graph execution

The demo runner now discovers nodes from the pressed Manual Trigger instead of sorting every canvas node by horizontal position. Nodes outside that reachable graph remain muted and display Disconnected. Sibling branches animate and run together, while downstream joins wait for their reachable parents.

## Validation

The release is validated with:

- an ASP.NET Core runner build with no warnings
- ESLint and TypeScript checks
- a production Next.js build
- live browser verification for copy/paste, grouped dragging, connection redirection, disconnected nodes, and parallel branches
- concurrent Python log-retention verification

## Notes

Papliba v0.7.0 substantially improves workflow editing and execution feedback. Workflow execution is still a frontend demonstration; logs currently capture simulated inputs and outputs rather than real Python stdout and stderr.
