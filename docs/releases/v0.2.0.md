# Papliba v0.2.0

Status: Released
Release date: 2026-08-05

## Highlights

- Added the GitHub Pages website with product overview, docs, changelog, and release notes.
- Added a customer-facing marketing homepage.
- Added editable markdown details for organizations.
- Added organization pinning.
- Added organization delete actions with name confirmation.
- Added a nested account menu with theme choices and a settings window.
- Improved sidebar collapse behavior with smoother motion and a compact icon rail.
- Hid the selected organization from the organization dropdown.
- Made organization search more compact.
- Removed the extra sidebar project search field.

## Notes

This release focuses on making the early Papliba workspace feel more like a real product while keeping the code small enough to explain step by step.
