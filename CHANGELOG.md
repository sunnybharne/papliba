## [0.8.0-alpha.1] — 2026-08-21

### Added

- React, TypeScript, and Vite product website with hash-based documentation routes.
- Responsive product, architecture, documentation, and roadmap pages.
- Proposed React → ASP.NET Core → Pi RPC architecture and ADR-001.
- Vitest, Testing Library, ESLint, Prettier, and strict TypeScript checks.
- Husky, lint-staged, Commitlint, Conventional Commits, and community files.
- GitHub Actions workflows for CI and GitHub Pages.

### Changed

- Rebooted Papliba from the discarded prototype with a new product direction.

### Archived

- Preserved the previous `0.7.0` prototype on the `archive/v0.7.0` branch.
