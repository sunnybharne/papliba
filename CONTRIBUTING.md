# Contributing

Papliba is early-stage. Contributions should stay small, clear, and easy to review.

## Local Setup

```bash
npm install
npm run validate
```

## Commit Messages

Use Conventional Commits:

```text
docs: add architecture note
chore: update project tooling
feat: add workflow runner
fix: correct broken diagram link
```

## Pull Requests

Before opening a pull request:

- keep the change focused
- update docs when behavior or project direction changes
- run `npm run validate`
- explain what changed and why
